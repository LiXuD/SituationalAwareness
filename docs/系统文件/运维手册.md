# 运维手册

> 适用提交：`d7d5916` ｜ 面向日常运维，命令均来自根 `Makefile` / `scripts/`。

---

## 1. 日常巡检

```bash
make ps                # 服务状态（opensearch/kafka/arkime 应 healthy）
make health            # 各服务健康检查
make branch-status     # 各分支事件量 + 最新上报时间（I-13）
make stream-status     # 流式引擎：消费量 / 位点滞后 / 实测时延（I-14）
```

**判读要点**
- `make branch-status`：某分支 `state=no_data` → 该分支边缘代理断链或停采，不影响其他分支。
- `make stream-status`：`lag` 持续增长 → 流式消费跟不上；`latency_ms.last` 异常大 → 检查 OpenSearch 写入。
- `make health`：探针数据源 `down/stale` → 见《故障排查手册》「探针断连」。

---

## 2. 服务启停

```bash
make down                    # 停止全部服务（**保留数据卷**）
make up                      # 启动（缺 .env 自动生成）

# 单个服务（注意：改源码后要 --force-recreate 重建，见《故障排查手册》）
docker compose -f deploy/compose.yml restart <服务>
docker compose -f deploy/compose.yml up -d --force-recreate <服务>
```

> `docker compose restart` **不清 filebeat 的读取位点**；要重新采集演示数据必须
> `make branch-demo` / `make demo`（内部用 `--force-recreate`）。

---

## 3. 演示数据回放

```bash
make demo            # 回放探针演示数据（logs/demo/ → 采集 → 关联 → 告警）
make clean           # 清空运行时回放暂存（logs/demo-stage、logs 根）
```

演示数据在 `logs/demo/`（真实可定位公网 IP，标记 `fields.demo=true`），由 `replay-demo.sh` 复制到
`logs/demo-stage/` 才被 Filebeat 采集。

## 4. 账号与权限（I-11）

| 角色 | 用户名 | 权限（PRD §11） |
|---|---|---|
| 技术负责人 | `admin` | 平台配置 / 探针管理 |
| 运维值班 | `ops` | 审批并提交拉黑 |
| 安全分析师 | `analyst` | 查看 / 研判 / 下钻 |
| 资产管理员 | `asset` | 资产增删改 |

- 初始口令在 `deploy/.env`（`SSP_<账号>_PASSWORD` / `SSP_DEFAULT_PASSWORD`），**生产必须轮换**。
- 重置账号：`scripts/gen-portal-user.py` 生成条目 → 写 `services/portal/users.json` → 重启 portal。

## 5. 资产与测绘（I-12）

```bash
make discover          # 触发一次被动测绘（Zeek 连接日志 → 候选池）
make discovery-status  # 候选统计
```

- 候选经 portal「资产测绘」页人工**采纳/忽略**；自动发现**绝不覆盖**人工字段（名称/重要度/责任人/风险分）。
- Excel 批量导入：模板 `scripts/gen-asset-template.py` 生成；失败整批回滚 + 逐行报错（见《故障排查手册》）。

---

## 6. 告警处置与落黑（I-05）

- 告警达处置级别（`SOAR_BLOCK_GRADES`，默认 P0）→ 生成拉黑草稿，**不自动提交**。
- 运维在「SOAR 审批」页确认后执行落黑（宿主 iptables 链 `SSP_BLACKLIST`）。
- 落黑失败：草稿 `status=failed`，告警保持 `open`，`response_action=block_failed`（含原因）。

---

## 7. 流式关联（I-14）

```bash
make stream-status            # 状态/位点/时延
make stream-demo              # 回放 + 观察秒级告警
make stream-demo --probe      # 投递一条事件到 ssp-ecs，实测端到端时延
```

- 实时位点 `ssp-stream`（`latest`）；重放用独立 group（`earliest`），互不影响。
- 位点落盘 `stream-offsets` 卷（`/var/lib/ssp-stream/offsets-<group>.json`），容器重建后续读。

## 8. 外部日志源（I-14，默认关闭）

```bash
make external-up / external-down     # 启停适配器
make external-demo / external-reset  # 样例 / 清理
```

---

## 9. 数据源健康与分支维护

- 分支登记：`services/portal/branches.py`，探测间隔 `BRANCH_PROBE_INTERVAL`（默认 300s）。
- 分支停用：portal「分支管理」置 `disabled` → 判定 `disabled`（区别于 `no_data`）。
