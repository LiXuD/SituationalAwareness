## 2. 平台账号（业务库）

| 用户名 | 角色 | 权限（PRD §11） | 口令变量（`deploy/.env`） |
|---|---|---|---|
| `admin` | 技术负责人 | 平台配置 / 探针管理 | `SSP_ADMIN_PASSWORD` |
| `ops` | 运维值班 | 审批并提交拉黑 | `SSP_OPS_PASSWORD` |
| `analyst` | 安全分析师 | 查看 / 研判 / 下钻 | `SSP_ANALYST_PASSWORD` |
| `asset` | 资产管理员 | 资产增删改 | `SSP_ASSET_PASSWORD` |

- 未单独设置时，各账号回退到 `SSP_DEFAULT_PASSWORD`。
- 初始口令由 `make init` 首次运行时随机生成并写入 `deploy/.env`（0600，已 gitignore）。
- 口令存储：业务库 `users` 表，PBKDF2-HMAC-SHA256（`scripts/init-db.py`，迭代 200k）。

| OpenSearch / Kafka | 无（内部网络，未启用安全认证） | — | POC 仅内网；生产须加安全插件 |

---

## 4. 密钥 / Token 存放位置与轮换

| 项 | 位置 | 轮换建议 |
|---|---|---|
| 平台口令 | `deploy/.env`（`SSP_*`） | 生产部署必轮换；轮换后重建 portal/soar |
| Arkime 口令 | `deploy/.env`（`ARKIME_ADMIN_PASSWORD`） | 同上报 |
| PostgreSQL 口令 | `deploy/.env`（`POSTGRES_PASSWORD`） | 轮换后 `make pg-init` 重建 |
| MISP API Key（可选） | `deploy/.env` 或环境变量 `MISP_API_KEY` | 不落库；过期即失效 |
| 业务库密码哈希 | `users.hash`（PBKDF2） | 改口令走 `scripts/gen-portal-user.py` → `users.json` |

---

## 5. 安全备注

- `deploy/.env` 已 gitignore，**不要**提交到仓库/资料库。
- 仓库（公开）内**不含任何可用口令**：模板 `deploy/.env.example` 值留空，代码只读环境变量。
- 若需在资料库共享账号信息，只写「角色 → 权限 → 口令变量名」，不写口令明文（本文件即按此原则）。
