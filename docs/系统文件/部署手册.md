# 部署手册

> 适用提交：`d7d5916`（口令 env 化后）｜ 本手册命令均来自根 `Makefile`，读者按步骤可独立跑通。

---

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 操作系统 | macOS / Linux（x86 私有化目标；Apple Silicon 亦可） |
| Docker | Docker Desktop（含 Compose v2，支持 `include` 聚合）；引擎 ≥ 24 |
| 内存 | 建议 ≥ 8GB（OpenSearch + Arkime + Kafka + Logstash + 各服务） |
| 磁盘 | ≥ 20GB 可用（OpenSearch/Arkime/Kafka 数据卷） |
| 网络 | 首次拉取镜像需外网；运行期各容器间走内部网络 `ssp` |

---

## 2. 目录与编排结构

```
deploy/
├── compose.yml              # 唯一入口：include 聚合 + networks(ssp) + os-data 卷
├── .env                     # 本地运行时配置（gitignore，由 make env 生成）
├── .env.example             # 配置模板（入库）
├── kafka/     logstash/     opensearch/   dashboards/
├── arkime/    portal/       correlator/   soar/
├── stream/                  # I-14 流式关联引擎
├── ingest-adapter/          # I-14 外部源适配器（profile external，默认不启动）
├── branch/                  # I-13 分支边缘代理
└── postgres/                # PostgreSQL 可选后端（profile postgres）
```

根 `compose.yml` 用 `include` 聚合各 per-service 片段，各片段内的相对路径以其自身目录为基准。

## 3. 首次部署步骤

```bash
# 1) 取代码
git clone <仓库地址> && cd <项目目录>

# 2) 生成本地配置（随机口令写入 deploy/.env，0600，不入库）
make env            # 或直接跳到第 3 步（make init 会自动生成）

# 3) 初始化业务库：建表 + 种子账号 + 登记默认分支 hq/sh-01/bj-01
make init

# 4) 启动全部服务
make up

# 5) 下发索引模板与检索别名（幂等，可重复执行）
make templates

# 6) （可选）回放演示数据
make demo

# 7) 检查
make health
make ps
```

访问入口：前端 `http://localhost:8088`（账号 `admin`，口令见 `deploy/.env` 的 `SSP_ADMIN_PASSWORD`）。

## 4. 常用 `make` 目标

| 目标 | 作用 |
|---|---|
| `make up` / `down` / `ps` / `logs` | 启停 / 状态 / portal 日志 |
| `make env` | 生成 `deploy/.env`（随机口令；已存在则不动） |
| `make init` | 初始化业务库（自动 gen-env + 建表 + 种子） |
| `make templates` | 下发 ECS/告警索引模板 + `ssp-events` 别名 |
| `make demo` | 回放演示数据 |
| `make verify` | 端到端验收 21 项（会重置演示数据） |
| `make health` | 各服务健康检查 |
| `make discover` / `discovery-status` | 资产被动测绘 / 候选统计 |
| `make branch-demo` / `branch-status` / `branch-down B=` / `branch-up B=` | 分支管理 |
| `make stream-status` / `stream-demo` | 流式引擎状态 / 演示 |
| `make external-up` / `external-down` / `external-demo` / `external-reset` | 外部源适配器 |
| `make pg-up` / `pg-init` / `pg-portal` / `pg-stop` | PostgreSQL 可选后端 |

## 5. 端口速查

| 端口 | 服务 | 说明 |
|---|---|---|
| 8088 | ui (nginx) | 前端入口（同源 `/api`） |
| 8093 | portal | 统一业务后端 |
| 8091 | correlator | 批式关联 |
| 8094 | stream | 流式关联（I-14） |
| 8092 | soar | 落黑执行器 |
| 8005 | arkime | Viewer |
| 9200 | opensearch | 检索/存储 |
| 5601 | dashboards | OpenSearch Dashboards |
| 5044 | logstash | Filebeat 接入 |
| 5514/udp, 5515, 5516 | ingest-adapter | 外部源（syslog/CEF/JSON，默认关闭） |
| 5433 | postgres | 宿主侧 PG（可选，容器内 5432） |

Kafka `9092` **不暴露到宿主**，仅容器网络内使用（`advertised.listeners=kafka:9092`）。

## 6. 配置（`deploy/.env`）

| 变量 | 用途 |
|---|---|
| `SSP_DEFAULT_PASSWORD` / `SSP_<账号>_PASSWORD` | 平台账号初始口令 |
| `ARKIME_ADMIN_USER` / `ARKIME_ADMIN_PASSWORD` | Arkime 鉴权 |
| `POSTGRES_USER/PASSWORD/DB/PORT` | PostgreSQL 可选后端 |

- `deploy/.env` 已 gitignore；模板 `deploy/.env.example`（值留空）。
- compose 自动读取该目录下的 `.env` 做 `${VAR}` 插值；宿主脚本由 `scripts/_env.py` 加载。
- 未配置口令时 compose 直接报错、`init-db.py` 中止，**不会退化成弱默认口令**。

## 7. 分支部署（I-13）

```bash
make branch-demo               # 重建各分支边缘代理，重新采集分支数据
# 单分支断链演练：
make branch-down B=sh-01       # 该分支 → no_data，其他分支不受影响
make branch-up   B=sh-01       # 恢复
```

新增分支：加一个边缘代理（`deploy/branch/` + 分支数据源），中心侧不改端口/管道。

---

## 8. 外部日志源（I-14，可选）

```bash
make external-up               # 启用适配器（profile external）
make external-demo             # 投递 syslog/CEF/JSON 样例并验证入库与关联
make external-reset            # 清理外部源演示数据
make external-down             # 关闭（回到默认"无副作用"态）
```

第三方设备 → `5514/udp`(syslog) / `5515`(CEF) / `POST :5516/ingest/json?source=&branch=`。
