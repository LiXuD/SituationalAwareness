## 逐迭代要点

### I-01 探针接入与 ECS 归一
- **目标**：Suricata / Zeek / Wazuh 三类探针事件经统一管道归一为 ECS Schema。
- **实现**：Filebeat → Kafka(`ssp-raw`) → Logstash（`00-inputs` + `05-branch` + `10/20/30-*`）→ OpenSearch。
- **实测**：A1 通过；三源事件 `fields.log_source` 区分，`ssp-events` 别名可检索。

### I-02 统一检索与存储增强
- **目标**：事件按 `ssp-<源>-日期` 分索引；Arkime 流量回溯。
- **实现**：`config/opensearch/ssp-ecs-template.json`；Arkime 直连同一 OpenSearch。
- **实测**：检索/Arkime 均通；模板 `dynamic:true` 支持 ECS 字段。

### I-03 轻量关联分析
- **目标**：窗口内跨源关联，产出 P0~P3 分级告警。
- **实现**：`services/correlator`（纯标准库），规则 R-001~R-007。
- **实测**：A2 通过；规则命中分布 `R-001:6 / R-002:5 / R-003:4 / R-004:2 / R-005:1 / R-006:5 / R-007:3`（演示数据）。

### I-04 MISP 情报对接
- **目标**：情报命中即升级；MISP 不可达不阻断。
- **实现**：本地种子情报（`threat_intel_seed.json`）+ MISP REST 双通道，超时 3s/缓存/熔断。
- **实测**：A3/A4 通过；`misp_unreachable=true` 时仍产出告警。

### I-05 Shuffle SOAR + 人工审批拉黑
- **目标**：达处置级别生成拉黑草稿，**不自动提交**；审批后执行落黑。
- **实现**：草稿状态机（业务库）+ `soar` 容器（privileged）写宿主 iptables 链 `SSP_BLACKLIST`。
- **实测**：A6/A7 通过；`draft_created → approve_approved → executed`。

### I-06 统一资产库
- **目标**：手工 + Excel 导入资产；失败回滚。
- **实现**：业务库 `assets` 表；`scripts/gen-asset-template.py`。
- **实测**：A9/N4 通过；导入含非法行 → 422 + 整批不写。

### I-07 态势大屏
- **目标**：攻击地图 / 告警 TOP / 资产热力 / SLA 达成率。
- **实测**：A8 通过（`http://localhost:8088/dashboard.html`）。

### I-08 POC 验收 Demo
- **目标**：模拟 + 回放完成端到端闭环（探针→告警→情报→审批→落黑→大屏）。
- **实测**：A1~A8 全绿，闭环时延 ≈12.8s。

### I-09 测试用例与验收
- **目标**：PRD §9/§10 全覆盖的可回归测试。
- **实测**：N1 探针断连 / N2 审批超时 / N3 落黑失败 / N4 导入回滚，均通过。

### I-10 统一平台整合
- **目标**：单一业务后端（portal）同源反代 `/api`，收口各服务。
- **实测**：A1~A8 回归全绿；前端改走同源，不再直连多端口。

### I-11 统一业务数据库与全量收口
- **目标**：业务对象（用户/会话/资产/候选/分支/审批/黑名单/配置/审计）入平台自有库。
- **实现**：SQLite 默认（`data/ssp.db`）；PostgreSQL 可选（profile `postgres`）。
- **实测**：回归全绿；SQLite 与 PG 双后端均验证。

### I-12 资产测绘自动化
- **目标**：Zeek 连接记录 → 候选池 → 人工采纳/忽略。
- **实现**：`services/portal/discovery.py`（进程内），授权网段 `cidr_allow`。
- **实测**：A9~A11 通过（幂等、采纳、忽略）；N5~N7（OS 不可达 502、越界 IP 422、analyst 403）。

### I-13 多分支汇聚
- **目标**：总部 + 各分行分支经中心 Kafka 汇聚，逻辑区分（非物理端口）。
- **实现**：`fields.branch → ssp.branch`；`deploy/branch/` 边缘代理；`services/portal/branches.py` 健康探测。
- **实测**：A13~A15、N10~N11 通过（分支打标/登记/断链隔离/未登记不阻断）。

### I-14 流式关联与外部日志源适配
- **目标**：秒级流式告警；防火墙/WAF 等外部源三入口。
- **实现**：`services/stream`（消费 Logstash 双写的 `ssp-ecs`）+ `services/ingest-adapter`（syslog/CEF/JSON）+ 共享内核 `services/common/ssp_kernel.py`。
- **实测**：A16 端到端 **1.05~1.19s**（阈值 ≤5s）、流式段 9~21ms；A17 幂等共存（同 `_id` 不重复计数）；A18 外部源适配与跨源关联；N12 消费者中断不丢事件；N13 外部源关闭零副作用。
