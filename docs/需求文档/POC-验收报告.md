## 1. PRD §9 EARS 验收逐条结论

| # | EARS 条款 | 验收结论 | 对应用例 / 证据 |
|---|---|---|---|
| 1 | Ubiquitous：统一以 ECS Schema 存储所有探针事件 | ✅ | **A1** 采集归一；Suricata/Zeek/Wazuh 三类事件经 Logstash 归一为 ECS，`ssp-events` 别名检索 |
| 2 | Event-driven：探针检测到已知攻击/流量回放触发告警 → 生成统一格式告警写入 OpenSearch | ✅ | **A2** 关联告警；`correlator`（R-001~R-007）产出分级告警到 `ssp-alerts` |
| 3 | Event-driven：告警源 IP/域名/哈希与 MISP 情报实时比对并标注命中 | ✅ | **A3** 情报匹配；`threat_intel` 命中即标 P0 |
| 4 | Unwanted：MISP 不可达 → 照常告警并标记"情报未匹配"，不阻断 | ✅ | **A4** 情报降级；`misp_unreachable=true` 仍产出告警 |
| 5 | State-driven：告警达自动处置级别 → 生成拉黑草稿；**不自动提交**，除非运维确认 | ✅ | **A6** 草稿生成不自动提交；草稿停留 `pending` |
| 6 | Event-driven：运维确认拉黑 → 执行落黑并回写，大屏可见 | ✅ | **A7** 人工审批落黑回写；iptables 链 `SSP_BLACKLIST` 生效 |
| 7 | Ubiquitous：大屏展示攻击地图/告警 TOP/资产热力/SLA 达成率 | ✅ | **A8** 大屏四视图 |
| 8 | State-driven：按级别 30min/10min/1min/秒级完成 SLA 并统计达成率 | ✅ | **A5** 分级 SLA；P0 秒级/P1 1min/P2 10min/P3 30min 阈值写入 `ssp.alert.sla_seconds` |
| 9 | Event-driven：手工/Excel 导入资产 → 更新资产库并使热力刷新 | ✅ | **A9~A11** 资产测绘/导入；资产库更新 |
| 10 | Unwanted：Excel 导入失败 → 回滚 + 报告错误行，不影响存量 | ✅ | **N4** 整批回滚 + 逐行报错（422） |

## 2. PRD §10 边界与异常 逐条结论

| 边界 | 结论 | 用例 |
|---|---|---|
| 情报平台不可达 | ✅ 告警照常，标"情报未匹配" | A4 |
| 审批超时 | ✅ 草稿保留、不自动提交 | N2 |
| Excel 部分失败 | ✅ 回滚 + 错误行报告 | N4 |
| 探针断连 | ✅ 标该源异常，不影响其他源 | N1 |
| 落黑失败 | ✅ 记录原因、告警保持待处置、通知运维 | N3 |
