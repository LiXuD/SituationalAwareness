## 逐项说明

### 1. 统一平台整合（I-10）
- **背景**：早期各服务各自暴露端口（portal 8093 / correlator 8091 / soar 8092 …），前端需多端口直连 + 处理 CORS。
- **变更**：新增统一业务后端 portal，前端同源 `/api` 反代到各服务（BFF）。
- **影响**：前端无需多端口；服务端口仍保留供直连调试。

### 2. 统一业务数据库（I-11）
- **背景**：资产、草稿、黑名单等业务状态一度借用 OpenSearch 索引，与检索型数据混在一起。
- **变更**：业务对象收口到平台自有库（SQLite 默认 / PostgreSQL 可选）。
- **影响**：新增 `db.py`（9 张表）+ 迁移脚本；检索型数据仍在 OpenSearch。

### 3. 资产测绘自动化（I-12）
- **背景**：PRD §14 将「资产测绘自动化（巡风/星林/Nuclei）」列范围外。
- **变更**：改为 **Zeek 连接日志被动测绘**（无侵入），候选池人工采纳。
- **影响**：新增 `services/portal/discovery.py` + 候选池表 + `make discover`。

### 4. 多分支汇聚（I-13）
- **背景**：PRD §14 将「多分支汇聚（R-12'）」列范围外；实际有总部 + 多分行场景。
- **变更**：各分支边缘代理 → 中心 Kafka(`ssp-raw`) 汇聚，`fields.branch → ssp.branch` 逻辑区分。
- **影响**：新增 `deploy/branch/` 边缘代理 + 分支登记/健康探测（`services/portal/branches.py`）。

### 5. 流式关联（I-14）
- **背景**：PRD §14 将「Metron 流式关联」列范围外；批式关联时延分钟级，不满足「秒级」诉求。
- **变更**：新增轻量流式关联引擎（纯标准库），消费 Logstash 双写的 `ssp-ecs`，秒级告警。
- **影响**：`services/stream` + 共享内核抽取 `services/common/ssp_kernel.py`（批式/流式共用规则）。

### 6. 外部日志源适配器（I-14）
- **背景**：PRD §14 将「外部日志源适配器（R-15）」列范围外；攻击面覆盖需接入防火墙/WAF。
- **变更**：新增 `services/ingest-adapter`（syslog 5514/udp、CEF 5515、JSON 5516），默认关闭。
- **影响**：外部源事件投递 `ssp-raw` → Logstash 归一 → 可检索、可被关联消费。

### 7. 项目上下文补齐（I-15）
- **背景**：「怎么部署/排障/验收/评审」散落在代码与对话中，无成文，接手成本高。
- **变更**：汇编 9 份文档（验收类 4 + 运维类 5），归档到资料库。
- **影响**：`需求文档/`、`系统文件/` 从空补齐。
